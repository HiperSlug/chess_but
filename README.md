# Chess But
Online chess where pieces gain the move sets of captured pieces. 

Made in Godot Engine.

[DEMO](https://hiperslug.itch.io/chess-but)

## Features
- Online multipler & local multiplayer
- Move history
- Dynamic move sets
- Normal chess rules

## Online
Clients send input to the server and the server keeps the client states in sync. Utilizes rpcs through Godots networking api.
